### Notes on assets

This repo ships with `index.html`, `style.css`, and `script.js` fully built out
against the layout and colors in `style-guide.md` and `preview.jpg`. The
markup references an `/images` folder (logo, nav icons, social icons, and the
hero photo) using the standard Frontend Mentor file names for this challenge,
e.g.:

```
images/
├── favicon-32x32.png
├── logo.svg
├── icon-hamburger.svg
├── icon-close.svg
├── icon-facebook.svg
├── icon-twitter.svg
├── icon-pinterest.svg
├── icon-instagram.svg
├── image-hero-mobile.jpg
└── image-hero-desktop.jpg
```

Drop the `images` folder from the original Frontend Mentor challenge download
into the project root and everything will resolve automatically — no markup
changes needed. The three feature icons ("Snappy Process," "Affordable
Prices," "People First") are inline SVG, so those render with no extra assets.
